Today I did the majority of Meyer's A+ course. The focuse was on POST (Power on Self Test) and it's uses. Here are my Notes!

Basic input / output services (BIOS). Most mother boards nowadays have a backup BIOS chip. BIOS programming enables interaction with motherboards before OS loads. Built into the back of cpus are the power good wire. This wire gives the cpu enough voltage to start running. The first thing it does is talk to the BIOS to run the power on self test BIOS is stored in nonvolatile media, thus called firmware. POST routines are built into firmware. The System Setup utility is also part of the firmware.

System setup is an aspect of BIOS that we can access in order to make changes. The System Setup enables custom information about changeable devices. System Setup enables changes to CPU frequencies, RAM timings, BIOS passwords, boot options, and more. An administrator password is so users must enter a password to enter and change things in BIOS. User password prompts the user to enter a password in order for the system to start booting.

POST runs at boot, requesting devices to self check. When there is an issue POST will cause beep codes in order for the user to know the problem. POST errors manifest as specific beep codes or display (text) codes. When a system is so in trouble that it can't even initiate a beep code you should plug in a POST card. POST cards enable testing of "dead" computers. POST codes are only valid as the computer is booting up. Once the OS kicks in they mean nothing.

Unified Extensible Firmware Interface (UEFI) is the newer version of BIOS. UEFI replaces traditional 16-bit BIOS in modern systems
